MEG Lab is a cloud electrophysiology workbench for magnetoencephalography: a responsive signal viewer, versioned analysis pipelines, explicit sensor geometry, and machine-readable experiment manifests. No server to configure, no analysis to reproduce by hand.

Capabilities

Signals, sensors, and science on the same project and artifact system

Display transforms are never recorded as analytical inputs. The recording is the primary content; everything else recedes.

Signals

A responsive multichannel viewer with channel grouping, time navigation, amplitude scaling, and event markers — plus filtering previews that never touch the stored recording.

  • Channel browser with explicit types and units
  • Event markers reconciled to a recorded time base
  • Multiresolution summaries for fast navigation

Analyse

Run versioned MNE-Python pipelines in isolated containers — filtering, epoching, evoked responses, spectral analysis — with explicit resource limits and honest status feedback.

  • Immutable pipeline versions pinned by image digest
  • Parameters rendered from a typed schema with units
  • Streamed logs that never leak credentials or raw signals

Sensors

Inspect sensor positions, orientations, and coordinate frames in 3D — essential for OPM-MEG where sensor geometry is flexible and can vary between recordings.

  • Declared coordinate frame and units for every layout
  • Sensor type and channel mapping visible together
  • OPM movement metadata where tracking data exists
